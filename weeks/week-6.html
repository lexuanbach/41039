    public static void main(String[] args) {
        Stock item = new Stock(4);

}
class Stock {
    private int stock;
    Stock(int stock) { this.stock = stock; }
    boolean take(int amount) {
        if (amount <= 0 || amount > stock) return false;
        stock = stock - amount;
        return true;

01Contracts and valid state

1.1Start with a promise

A class is useful when it gives the rest of the program a dependable promise. A stock item starts with a non-negative quantity; a successful withdrawal reduces it by exactly the requested positive amount; a rejected withdrawal changes nothing. These rules are its invariant and method contract.

Write down the inputs, result and state change before writing the method body. Test zero, negative amounts, exactly the available quantity and one too many. A getter reports a value; a mutator changes the model. Keeping these jobs clear makes a failing test easier to explain.

1.2Hide the path around the rule

Java private prevents an outside caller from assigning a field directly. Python _stock communicates intended use but does not enforce privacy. In either language, public methods should be the normal route for changing state. Constructor validation must establish the same invariant that later methods preserve; these small examples assume a valid starting quantity.

  1. Use this to name the object field, rather than the parameter.
  2. Compute a new balance only after the request has been validated.
  1. Each object owns its own stock count; the underscore is a convention.
  2. Reject the request without changing the stock.
Predict · run · change · explain

Change a request to 0 and then to the exact remaining stock. Explain why the field changes in one case and stays unchanged in the other.

02References and object lifetime

2.1Draw objects separately from names

b = a copies a reference in both languages. Draw two arrows to one object, then trace a mutating call through either arrow. Creating another object requires another constructor call. Two objects with equal field values need not be the same object.

2.2Instance collections belong in the constructor

A Python list in the class body is shared. A list assigned to self.items in __init__ is created for each instance. Compare that rule with Java instance fields and static fields. Before explaining output, count allocations, not variable names.

  1. Copy the reference, not the object.
  2. Ask whether these references identify the same object.
  1. Create a fresh list whenever __init__ runs.
  2. Compare object identity, not the contents of the baskets.
Predict · run · change · explain

Make b refer to a in the Python example. Predict which output lines change before running it.

03Shared data and instance data

3.1A counter is a deliberate shared responsibility

A shared ticket counter is appropriate when every new ticket must receive the next number. The ticket's own number is instance data. Updating the shared counter later does not rewrite existing ticket numbers.

3.2Mutation differs from rebinding

Appending to a shared class list changes that one list. Assigning a.items = [] instead creates an instance attribute that shadows the class attribute for a. This is why the location of allocation matters more than whether the expression contains an object name.

  1. One shared counter belongs to the class.
  2. Assign an individual number once for this ticket.
  1. This list is constructed in the class body and shared by these instances.
  2. Mutate the shared list; this does not assign a new instance attribute.
Predict · run · change · explain

Repair the shared Python basket by writing __init__. Construct two baskets and prove that adding to one does not change the other.

04Composition and a small public interface

4.1A has-a relationship

A shelf holds a book; it is not a special kind of book. A field that refers to another object expresses this composition. Give the class with the data the job that uses it: Book knows its title, while Shelf decides how to describe its contents.

4.2Make observations easy

A useful string representation helps a person inspect state while debugging. Return a string from __str__; do not print inside it. In Java the corresponding method is toString(). Keep presentation separate from the operations that update the model, so a formatting change does not change the rules.

  1. A Shelf has a Book; it does not need to inherit from Book.
  2. Ask the contained object for the information it owns.
  1. Return the text that print should use for this object.
  2. Read data from the current book.
Predict · run · change · explain

Extend Shelf to contain two books. Decide which object should know a book title and which should know the number of occupied slots.
